# Audit records

Everything here is a record: append-only, lint-exempt (`docs/audit/` prefix),
and true of the day it names. A number in a dated report is not maintained,
so re-verify before acting on it. The running findings log is the root
[`AUDIT.md`](../../AUDIT.md); verdicts on levers are
[`../roadmap.md`](../roadmap.md).

**Read [`SETTLED.md`](SETTLED.md) before forming an audit hypothesis, not while
verifying one.** The 2026-07-29 architecture audit spent most of its budget
refuting its own hypotheses; that file is the list nobody needs to re-chase.
