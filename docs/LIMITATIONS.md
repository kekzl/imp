# Limitations

What imp does not do, does badly, or does without a test behind it. Absences by decision:
[`DESIGN_DECISIONS.md`](DESIGN_DECISIONS.md).

## Five things to weigh first

1. **One GPU, one chip**: `sm_120a` only, no multi-GPU, no tensor parallelism, no other vendor or generation ([`internals/ARCHITECTURE.md`](internals/ARCHITECTURE.md)).
2. **One model resident at a time**: 32 GB fits one; a second model means a swap, paid by the requesting call.
3. **No GPU in CI**: every kernel-level correctness and perf check runs on the maintainer's machine before a push.
4. **Decode measurements move several percent between sessions** on this host; one number is one sample of a distribution ([`PERF.md`](PERF.md)).
5. **Single-author project**: no support rotation, no SLO, no security response process.
